# Shared

The domain core both the web app and the backend import: dates and the Booking Window, Session times (a Group's usual start time, length and time zone, a Session's start and end, and Reminder due times), Answers, month summaries and Best Nights, names, Share Token shape, limits, legal versions, and the iCalendar text of calendar files and invites (`icalendar.ts`).
